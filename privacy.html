ClipGTA6 – Privacy Policy

Last updated: November 19, 2026

1. Who we are

ClipGTA6 is a personal, non-commercial tool used by a single creator to send short video clips as drafts
to their own TikTok account through the official TikTok Content Posting API.

2. Data we access

When the account owner authorizes the application, it receives:
- basic profile information (user.info.basic), used only to confirm which account is connected;
- permission to upload videos as drafts (video.upload).
The application does not access followers, messages, comments, analytics or any other TikTok data.

3. How data is stored

The access token is stored only on the account owner's personal computer. No data is sent to any server
other than TikTok's own API. No data is sold, shared with third parties, or used for advertising.

4. Data retention and deletion

The account owner can revoke access at any time from the TikTok app (Settings > Security >
Manage app permissions). Deleting the local token file removes all stored data.
